# 森タイル制作 進捗記録

## 制作方針
- GitHubにある中央ヘックスの見本を基準にする。
- GitHubにある7ヘックスのベース画像を使用し、形・大きさ・配置を変更しない。
- 7ヘックス全体に連続した森を最初から1枚絵として描く。
- 中央から周囲へ木の密度・草地・地面のつながりを自然に構成する。
- 7ヘックス全体を確認・修正してから7枚に分割する。
- 分割後、ゲーム上で再結合して継ぎ目を確認する。
- マスター地図は変更しない。個別タイルを別々に描いて無理に接続しない。

## 作業順
1. 中央ヘックス見本と7ヘックスベース画像を確認
2. ベース画像を固定
3. 7ヘックス全体の森を一枚絵として制作
4. 全体を確認・修正
5. 7枚に分割
6. ゲーム上で再結合し、境界・継ぎ目を確認
