# 森タイル制作 進捗記録

## 制作方針
- GitHubにあるゲームのCSS/JSを確認し、ヘックス形状・寸法・間隔を正確に合わせる。
- ヘックスを個別に描かず、まず連続した森の絵として制作してからタイルに切り出す。
- タイルの境界、透明部分、サイズを全種類で統一する。
- 分割後にゲーム内で再結合し、継ぎ目と配置互換性を検証する。
- マスター地図や既存の地形基準は許可なく変更しない。

## タイル数と管理方針（暫定決定）
- 基本セットは19枚（中心1＋第1リング6＋第2リング12）を目標とする。
- 37枚などの大型セットは初期制作では採用しない。必要になった場合のみ後から追加する。
- 1枚ごとに独立した画像ファイルとして管理し、コード側で扱いやすい短く明確なファイル名を付ける。
- ファイル名は用途・方向・役割を示し、単なる通し番号だけにしない。
- 19枚の個別画像と配置・隣接情報をセットで記録する。

## 19枚の配置案（仮・描画前に検討する配置記録）
ヘックスはゲームのCSS準拠の形・寸法・オフセットを保ち、中心＋2リング構成で配置する。
- 中心：1枚
- 直近リング：6枚（北、北東、南東、南、南西、北西）
- 外側リング：12枚（第1リングの隣接関係に沿う外周12位置）
- これは配置の骨格案であり、個々の森画像の完成版ではない。外周12枚の具体的な位置番号・隣接一覧・画像切り出し座標は、正確なヘックス座標で図にして確認してから確定する。
- タイルを任意に組み合わせた際に、森の縁・木々・地面の境界が不自然に途切れないことを優先する。必要なら「中心用」「内側用」「外周用」「角/端用」など役割の違う素材タイルを用意する。ただし、役割だけで置き場所を固定しすぎず、組み替えやすさも検討する。

## ファイル名案（暫定）
- forest_center.png — 中心タイル
- forest_ring1_n.png / forest_ring1_ne.png / forest_ring1_se.png / forest_ring1_s.png / forest_ring1_sw.png / forest_ring1_nw.png — 第1リング
- forest_ring2_01.png ～ forest_ring2_12.png — 外側12位置（配置図確定後、方角や役割を反映した名前に変更する）
- 名前は最終的に各タイルの内容・配置・用途を確認して確定。重複・曖昧な名前は避ける。

## 制作手順
1. 正確なヘックス基準を再確認し、19枚の仮配置図（座標・方向・隣接）を作成して記録する。
2. 19枚の組み合わせ/配置案をレビューし、隣接の接続関係と切り出し範囲を確定する。
3. ヘックス土台と余白を固定。
4. 19位置をカバーする連続した森林イラストを描く（個別に描かない）。
5. 全体を確認・修正。
6. 正確なマスクで19枚に分割し、上記命名規則に沿って保存。
7. ゲーム上で再配置して継ぎ目・互換性を確認し、必要な修正を行う。
