# 世界観設定・深掘り進捗管理

このファイルは、世界観の設定を深掘りする際の共通チェックリスト兼進捗記録。
今後「世界観の設定を深めよう」「世界観を詰めよう」などの話が始まったら、まずこの一覧と現在の進捗を確認して提示する。

## 進捗の基準
- **未着手**：具体的な検討をまだ始めていない
- **検討中**：一部案があるが、主要な決定が残っている
- **部分整理済み**：既存設定・案がある程度まとまっているが、全体の確定には至っていない
- **確定**：ユーザーが明確に決定した内容を整理・保存済み

進捗は会話とGitHubの設定資料を照合して更新する。こちらから勝手に案を確定扱いにしない。

## 進め方
1. 世界観深掘りの会話開始時に、この一覧を見せ、各項目の進捗を短く案内する。
2. ユーザーが選んだ項目を一つずつ深掘りする。複数項目を同時に確定しない。
3. 決定事項は既存の世界設定資料に反映し、必要に応じてこの進捗ファイルのチェック・状態・メモも更新する。
4. 決定事項、暫定案、未決定事項を明確に区別する。
5. 既存設定との矛盾があれば、勝手に修正せず、矛盾点を示して相談する。
6. 作業終了時は、今回の進捗と次に取り組む候補をこのファイルに記録する。
